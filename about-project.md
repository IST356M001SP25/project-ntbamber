### What it does
This is a Streamlit dashboard that visualizes diabetes statistics from the CDC. It includes:
- A box plot that displays the distribution of diabetes prevalence across demographic groups for a year and state.
- A bar chart that shows the age-adjusted diabetes mortality rate (per 100,000 people) by state for a year and group.
You can filter by year, state, group type, and demographic group.

### How you run my project
To run my project you must run extract.py then transform.py through the python debugger. To display the dashboard you run app.py with the streamlit debugger.

### Other things you need to know
streamlit, pandas, plotly, and requests are all required to run this project.
